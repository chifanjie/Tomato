# Wiki 阅读体验修复 PRD

日期：2026-09-20

范围：Understand Code 知识库阅读器；以 Spring Breeze 知识库为验收样本。

## 1. 目标

让读者能连续阅读生成的 Markdown，识别文件路径，打开文档与源码证据，并看懂流程图。先完成本 PRD，再实施与验证。

| 编号 | 优先级 | 问题与证据 | 用户影响 |

## 3. 产品方案

采用阅读器统一适配方案：保留原始 Markdown 与索引事实，在展示层识别路径、解析链接、渲染图表和改善排版。单独手改 Spring Breeze 文档不能解决其他项目；开放任意本地文件 HTTP 路由也不能保证发布快照内容完整，因此不采用这两种方案。

### 3.1 路径展示

- 路径使用等宽字体、浅色背景、边框与文件标记，视觉上区别于正文和普通链接。
- 识别段落/列表/表格中的明确文件路径及行内代码路径；不处理代码块内部，不将 URL、API 路由或普通斜杠词组误识别为文件。
- 保留完整路径；允许换行；提供有反馈的复制操作。已有语义链接文字保留，例如“服务端入口”，同时可查看目标路径与行号。
- 根目录、知识库目录等信息按源文档分行展示。

### 3.2 链接行为

| 类型 | 行为 |
| --- | --- |
| 已索引 Wiki 文档 | 在阅读器中切换，支持中文、相对路径、已知绝对路径及章节定位 |
| 当前文档或其他文档章节 | 定位章节；不存在时在阅读器内提示，可继续阅读 |
| 已收录源码 | 打开已有源码预览/证据，尽量定位原行号；保留返回阅读上下文 |
| 外部 HTTP(S) / 邮件 | 保持有效外链语义，外部网页在新标签打开 |
| 未发布文档、附件或无法匹配的本地文件 | 留在当前页，明确提示“当前知识库未收录此资源”，显示原路径与复制入口；不能渲染成会进入空页面的裸链接 |
| 加载失败或空正文 | 显示与原因相符的错误和重试入口，不将 HTML 应用壳误作 Markdown |

只按实际索引映射，禁止凭同名文件猜测源码。没有内容时不虚构预览，也不把“未收录”伪装成正常文档。

### 3.3 Markdown 与图表

- Mermaid 按需加载并在本地渲染为 SVG；使用严格安全配置，不执行文档脚本或图中动作。
- 图表具有标题/可访问名称，支持查看图表源码；渲染失败显示明确原因和保留的源码，正文仍可阅读。
- 有语言和无语言代码围栏均按代码块显示，保留缩进与换行；普通行内代码继续使用轻量样式。
- 安全识别 Markdown 中的 `<br>` 换行；保留代码中的 `<...>`、`&` 等真实内容，不做全局字符删除或全局反转义。
- 保持 GFM 表格、列表、任务列表、删除线、引用与编号的标准语义；补全自然标题锚点与目录一致性。

### 3.4 阅读布局与辅助信息

- 扩大桌面正文可用宽度并减少侧向空白；段落保持合理行长。
- 表格设置合理单元格宽度和行距，表头不逐字折行；超宽时只在表格容器中横向滚动，键盘可操作。
- 目录/证据栏继续支持现有收起与小屏抽屉；小屏页面不出现整体横向溢出。
- 目录页显示“知识库目录”，普通 topic 显示“专题文档”；文档计数保留“篇”；空的相关资料列表不占一个折叠区。
- 错误提示、路径、图表、代码块和表格适配现有主题颜色。

## 4. 实施边界

- 修改共享阅读器，不重写业务分析结论，不改变代码证据的真实性等级。
- 不读取私密环境配置或运行数据库；源码仍经已有索引和访问控制读取。
- 保留工作区已有修改：hooks、WorkbenchLaunchGate 与 workbench-runtime 的非本次改动。
- 本次不增加编辑器、附件发布系统、远程图表服务或新的业务数据模型。
- 未发布的图谱说明与 draw.io 附件先提供明确的未收录状态；既有关系图谱入口仍可使用。

## 5. 验收标准

1. 目录、总览、至少两篇专题和代码参考页可读；根目录/长文件路径有独立样式并可复制。
2. 站内 Markdown 链接正常切换，中文标题锚点可定位；本地源码打开预览或明确的不可用状态。
3. “项目图谱说明”“可编辑 draw.io 图谱”不再跳出到 `not_found` 页面。
4. 文档关系图和专题流程图显示 SVG；无效 Mermaid 保留正文和源码，不导致白屏。
5. 代码围栏、`<br>`、表格、编号列表及特殊字符通过渲染回归验证。
6. 宽屏正文更充分利用空间，表头不出现单字竖排；窄屏只在表格/代码/图表内部滚动。
7. Wiki 相关自动测试、Dashboard 类型检查与构建通过；浏览器复核原始故障与主要交互。

## 6. 执行顺序

1. 写入本 PRD 并检查范围与验收条目。
2. 并行修复资源链接解析与 Mermaid 渲染；补充能够复现故障的测试。
3. 集成路径样式、Markdown 兼容、排版、分类和计数文案。
4. 运行测试/构建，在本地页面验证，记录结果与未发布资源限制。
